## 2. 迁移后结构性校验（本机可做）

样本为 `/tmp/cmp_text_{2,5,10}.json` 与 `/tmp/cmp_tools_{2,5,10}.json`，是 Claude 格式的真实请求样本（原请求 `model` 均为 `glm-5.3`）。`cmp_text_N` 把 N 个工具定义以 JSON 文本内联在 user 消息中，`tools` 字段为空；`cmp_tools_N` 把同样 N 个工具放在 `tools` 字段。二者合计 6 个样本。

计算方式：用当前分支的 `relaykit/dto.ClaudeRequest.GetTokenCountMeta()` 得到 `CombineText` 与 `ToolsCount`，再用 `tokenkit.Count(model, CombineText)` 估算 token；`model` 取样本自身的 `glm-5.3`（在 `tokenkit` 中归为 `FamilyUnknown` 权重）。临时程序放在 `/tmp/tokencmp/`，未进入仓库、未提交。

| 样本 | tools 数 | CombineText 字节数 | 估算 token | 每字节 token 比 |
|---|---:|---:|---:|---:|
| cmp_text_2.json | 0 | 1674 | 465 | 0.278 |
| cmp_text_5.json | 0 | 3441 | 959 | 0.279 |
| cmp_text_10.json | 0 | 6173 | 1677 | 0.272 |
| cmp_tools_2.json | 2 | 1611 | 447 | 0.277 |
| cmp_tools_5.json | 5 | 3248 | 903 | 0.278 |
| cmp_tools_10.json | 10 | 5770 | 1562 | 0.271 |

校验结论：

- **工具数递增时估算单调递增**：文本样本 465 → 959 → 1677，工具样本 447 → 903 → 1562，均随工具数（0/2/5/10）严格递增。
- **每字节 token 比处于合理区间**：6 个样本为 0.271–0.279，落在英文文本约 0.2–0.35 的参考区间内。
- **文本样本与工具样本的比值随工具数增长**：文本/工具 token 比在 2、5、10 个工具时分别为 1.040、1.062、1.074，随工具数增加而增大，说明同一份工具定义经 `tools` 字段承载时估算更紧凑，且差距随工具数扩大。
- 补充：若把同一批样本按 Claude 权重（`claude-sonnet-4-5`）复算，每字节 token 比为 0.302–0.311，单调性与文本/工具比值趋势一致，结论不变。

以上只是结构性一致性校验（单调性、量级、相对趋势），**不构成与上游真实 `usage` 的偏差测量**。

## 3. 结论与限制

- 本机**无法**验证迁移后估算值与上游真实 `usage` 的绝对偏差：迁移前的 6 组 payload 未保留，且没有可消耗的上游配额做新采样。
- 迁移后的绝对精度由 **S2 部署验证**作为权威判定：向真实 Claude Code 发请求，用上游返回的 `usage` 与本地估算对账。
- 迁移前基线最大绝对偏差为 4.6%，规格要求 ≤10%；本机结构性校验未发现单调性或量级异常，但不足以替代 S2 的绝对偏差结论。
- 本次结构化样本的 `model` 是 `glm-5.3`，按 Claude 权重复算的补充结果也正常；真实 Claude Code 请求会走 `FamilyClaude`/`FamilyClaude47` 权重，仍需 S2 覆盖。

## 4. 对 Gate G3 的影响

Gate G3 的验收条件是「本地估算与上游真实 `usage` 的最大偏差 ≤ 10%」。该条件**本机不可验证**（无夹具、无上游配额），**顺延至 S2 部署验证**判定；本记录只提供迁移前 6 组历史基线与迁移后的结构性校验，不改变 G3 的待验证状态。
